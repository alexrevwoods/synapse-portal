# Member navigation, Portal sections, and topic discovery verification

Desktop verification confirms that an authenticated visit to `/` is immediately rendered as Discover rather than the public marketing landing page. The signed-in global navigation exposes **Discover** and **Feed Signals**, with the account workspace retained as **My Portals**. The new member Feed displays the selected Profile's chronological following stream and provides a clear empty state for new accounts.

The public Portal now has active Portal, Feed, About, and Network section buttons. Each button scrolls to a real section rather than behaving as a disabled visual label. The Portal includes the interactive map, Feed displays published Signals, About includes identity context and external website, and Network exposes only accepted, published relationships. Duplicate public relationship cards are removed at the data layer.

The 390px mobile captures show compact section controls, a reachable map, readable Signals, About, and Network cards without horizontal page overflow. The Account workspace now contains an interest editor for an existing Profile. Topic discovery pages render responsive Portal and Signal areas with an explicit empty state until members select a matching interest.
