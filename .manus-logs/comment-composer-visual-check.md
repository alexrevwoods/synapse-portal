# Public feed discussion composer verification

Public Portal feeds use compact Signal cards. The prior compact branch suppressed the whole discussion area, leaving the Comment control without a reachable input. The card now keeps compact feeds collapsed by default but turns the Comment pill into an explicit discussion trigger for signed-in members with an active Portal. Selecting it expands the current comment thread, focuses the inline editor, and supports both new comments and replies. Visitors without a Portal see a direct creation path instead of an inert control.

TypeScript compilation, the six-file Vitest suite with 13 assertions, and the production build all completed successfully after the repair. A responsive full-page public Portal capture confirmed the compact Signal layout remains intact before a member opens a discussion.
