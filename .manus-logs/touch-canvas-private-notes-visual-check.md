# Touch canvas and Private Notes verification

The full-page 390px Builder view confirms that the map toolbar retains explicit zoom controls, percentage indicator, Reset action, Tidy map action, and the in-map Place Node action in the mobile layout. The touch map now prevents browser-native touch zoom within the map surface and responds to two-finger pinch/pan gestures, while preserving the explicit placement mode.

The responsive Signals view retains the compact Private note audience selector and its dedicated Private Notes workspace. The reminder date control is intentionally conditional: it appears only after the owner selects Private note, keeping public, follower, and connection composer interfaces focused and ensuring public visitors never see private note data, pins, or reminder dates.
