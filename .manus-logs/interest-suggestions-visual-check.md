# Interest personalization and follow suggestions verification

The desktop Discover view renders a visible **Intentional suggestions** panel above Portal results for the signed-in Media Revolution Profile. Each suggestion exposes a human-readable reason, such as a shared interest, shared Connection, identity type, or a transparent recently-active fallback. The follow action is available inline without forcing an opaque ranking.

The 390px onboarding flow keeps interest selection optional and compact after identity type selection. It clearly describes the purpose, displays a six-interest maximum, avoids changing public Profile content, and preserves the primary account-creation action within the mobile viewport.
