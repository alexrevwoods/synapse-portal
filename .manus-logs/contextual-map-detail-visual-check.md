# Contextual Node detail verification

A Node selection now opens one shared contextual popover for desktop and mobile, positioned directly beside the selected Node. The former mobile bottom sheet and desktop corner card have been removed. The popover opens above most Nodes or beneath Nodes in the top map region, with left- and right-edge alignment to keep it inside the visible network canvas.

In mobile full-network mode, lower controls remain temporarily hidden while a contextual detail is open. TypeScript, 13 automated assertions, and the production build pass.
